FX & Derivatives Monitoring is a web application used to manage and monitor foreign exchange and derivatives transactions to make sure it's compliance with central bank policy.

![Menu for managing transactions](/fx-1.jpeg){.img-lg .mx-auto .rounded-lg}

The main feature of this application such as:
- Upload & process transaction data from multiple source and compile to create final transaction data
- Monitor over-threshold transactions and send report to stakeholder
- Gather underlying document for over threshold transaction and calculate the amount
- Reporting with template compliance with central bank policy
