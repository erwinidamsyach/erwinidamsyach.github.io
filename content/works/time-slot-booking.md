For manufacturing sector, raw material availability on site is uncompromised. Raw material should be available when needed and it should be delivered on time. Other than that, factory have limited space for storing raw material, so raw material delivery to factory should be just on time and on place.

![Time Slot Booking](/tsb3.jpg){.img-lg .mx-auto .rounded-lg}

Time Slot Booking (TSB) is build to help that issue. in TSB, supplier should book a time slot to deliver raw material to factory, including the material they deliver, and transporter information. System also able to limiting the number of truck that can enter the factory based on the time slot, so the factory will not crowded with truck. 

![Time Slot Booking](/tsb4.jpg){.img-lg .mx-auto .rounded-lg}

For the factory side, this system also help Good Receipt (GR) process. The old way to process GR is by watching the document of delivery, then input it on the SAP system without checking the real condition and amount of the material. TSB change it with actual checking, by using mobile app, receiver come to the loading dock, scan the QR code in receipt document, check the amount and condition of the material, then input the received amount on the mobile app. The system already connected to SAP system using API, so the receiving process would be much easier and factual.
